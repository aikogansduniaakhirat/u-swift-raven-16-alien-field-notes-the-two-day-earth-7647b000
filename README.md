An alien tourist's one-line review of planet Earth, ≤200 characters, written by a
program the grader runs twice. The line is rendered from a small review model
(stars, verdict, closing remark) in `main.ts` — no network, no clock, no randomness.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
